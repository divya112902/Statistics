# EXP 1 – Exploratory Statistical Analysis

## Description

- Performs Exploratory Data Analysis (EDA) on the Pima Indians Diabetes Dataset.
- Examines the structure, variables, data quality, statistical characteristics, and patterns in the dataset.
- Identifies missing/invalid values and potential outliers.
- Uses statistical summaries and visualizations to understand the dataset.

## Dataset Used

- **Dataset:** Pima Indians Diabetes Dataset
- **Observations:** 768
- **Input Attributes:** 8

## Requirements

- Python 3.x
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## Installation

Install the required libraries using:

```bash
pip install pandas numpy matplotlib seaborn
```

## Run

1. Open the EXP 1 Python file or Jupyter Notebook.
2. Load the Pima Indians Diabetes Dataset.
3. Run the code program.


## Outputs

- Dataset dimensions and column information
- Data types
- Sample records
- Statistical summary
- Missing/invalid value analysis
- Outlier analysis
- Histograms
- Boxplots
- Bar charts
- Scatter plots


## Notes

- Zero values in Glucose, BloodPressure, SkinThickness, Insulin, and BMI may require investigation.
- Outliers should be investigated before removing them.
- The analysis is performed for understanding the dataset before further statistical or machine learning analysis.
