# EXP 4 – Statistical Estimation and Hypothesis Testing

## Description

- Applies statistical estimation and hypothesis testing techniques to the Pima Indians Diabetes Dataset.
- Uses sample data to estimate population characteristics.
- Constructs confidence intervals for selected parameters.
- Performs hypothesis tests using appropriate statistical methods.
- Interprets test statistics and p-values.

## Dataset Used

- Dataset: Pima Indians Diabetes Dataset
- Observations: 768
- Input Attributes: 8

## Requirements

- Python 3.x
- Pandas
- NumPy
- SciPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## Installation

Install the required libraries using:

pip install pandas numpy scipy matplotlib seaborn

## Run

1. Open the EXP 4 Python file or Jupyter Notebook.
2. Load the Pima Indians Diabetes Dataset.
3. Select the required variables and groups.
4. Calculate point estimates and confidence intervals.
5. Perform the selected hypothesis tests.
6. Observe the test statistics and p-values.
7. Interpret the statistical results.

## Outputs

- Sample mean
- Sample proportion
- Confidence intervals
- Test statistics
- p-values
- One-sample t-test results
- Two-sample t-test results
- Chi-square test results
- Hypothesis testing decisions
- Statistical interpretations

## Notes

- A significance level of "α = 0.05" may be used.
- If "p-value < α", reject the null hypothesis.
- If "p-value ≥ α", fail to reject the null hypothesis.
- The selected statistical test should match the type of data and research question.
