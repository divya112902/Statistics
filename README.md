# Statistics

Repository of statistical experiments and analyses performed in the lab.

## Overview

This repository contains statistical experiments performed using Python on the Pima Indians Diabetes Dataset. The experiments cover exploratory data analysis, descriptive statistics, statistical estimation, hypothesis testing, bootstrap resampling, and permutation testing.

## Experiments

- **EXP 1 — Exploratory Statistical Analysis (EDA)**  
  Examines the structure, variable types, data quality, statistical characteristics, and important patterns in the Pima Indians Diabetes Dataset.  
  
- **EXP 2 — Descriptive Statistics and Data Visualization**  
  Applies descriptive statistical techniques to study central tendency, dispersion, distributions, and relationships between variables using suitable visualizations.  
  
- **EXP 3 — Statistical Analysis**  
  Performs statistical analysis using appropriate statistical techniques and interprets the obtained results.  
  
- **EXP 4 — Statistical Estimation and Hypothesis Testing**  
  Performs point estimation, confidence interval estimation, and hypothesis testing using one-sample t-test, two-sample t-test, and chi-square test.  
  
- **EXP 5 — Bootstrap and Permutation Resampling**  
  Uses bootstrap resampling to estimate sampling distributions and confidence intervals, and permutation testing to analyze differences between groups.
